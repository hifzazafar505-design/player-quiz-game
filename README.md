# 🎮 Player Quiz Game

A simple **console-based Quiz Game built with Python**.

## 📌 Project Overview

This project allows the player to:

* 📋 View available questions
* ▶️ Start the quiz
* 📊 View the quiz score
* 🚪 Exit the game

## 🧠 Concepts Used

* Variables
* Input
* Lists
* Dictionaries
* Loops
* Functions
* Conditions

## ✨ Features

### 📋 Show Questions

Displays all available quiz questions.

### ▶️ Start Quiz

Starts the quiz and asks the player each question one by one.

### 📊 Show Score

Displays the player's current score and total number of questions.

### 🚪 Exit

Closes the quiz game.

## 🛠️ Technologies

* Python 3

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python player_quiz_game.py
```

## 📝 Example Questions

The current quiz includes questions such as:

* What is the capital of Pakistan?
* 2 + 2 = ?
* Python is a ______ language.
